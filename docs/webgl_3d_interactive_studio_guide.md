# Three.js 3D 黏土工坊与 2.5D 法线双模检视系统接入指南 (WebGL 3D Studio Guide)

> **适用项目**：Tank Battle (Godot 4.5+ / WebGL 3D Studio)  
> **服务目录**：`G:\tools\treee.js-project1`  
> **功能定位**：360° 自由精修、部件爆炸图拆解、受损模拟、Godot 2D/3D 并排对齐、3D 战场模拟器

---

## 1. 快速一键启动 (Quick Start)

在 Godot 项目根目录下，或进入 `G:\tools\treee.js-project1` 目录：

- **Windows 批处理一键启动**：双击运行 `tools/launch_3d_clay_studio.bat`（或 `G:\tools\treee.js-project1\start.bat`）；
- **终端 Python 启动**：
  ```powershell
  python tools/launch_3d_clay_studio.py
  ```
  本地服务器将自动寻找可用端口（默认 `http://localhost:8080`）并在浏览器中唤起 3D 视图。

## 2. 核心功能操作指南

### 2.1 模块一：模型精修工坊 (Studio Mode)
1. **资产全量分类浏览**：
   - 🛡️ **玩家战车**：Tier 0~3 升级形态；
   - 🤖 **敌军机甲**：14 款特化敌机（工程抢修车、四足步行机甲、钻地沙虫、分裂母机等）；
   - 👑 **史诗 Boss**：剧毒巨蝎、太阳泰坦、猛犸重炮；
   - 🧱 **地形瓦片** / 🏛️ **建筑设施** / ⭐ **道具宝物** / 💥 **3D 黏土特效**；
   - 🕹️ **Godot 原作资产**：直读 Godot 2D 离线序列帧、法线贴图与 3D GLB 原生模型。
2. **动作与物理模拟测试**：
   - `💥 开火后坐抛壳`：体验炮管挤压拉伸回弹、车体反作用力冲量与 3D 棱星火光；
   - `💢 承受弹击破片`：体验白热受创闪光与手捏碎块飞溅；
   - `💚 战地纳米修复`：触发翠绿矩阵光环与形变复原；
   - `🔨 彻底摧毁残骸`：直接切换为焦黑碳化战损残骸；
   - `受损程度滑块`：0% ~ 100% 五阶段受损状态平滑拖拽预览。

### 2.2 模块二：Godot 2D/3D 双模对比与法线光照
- **并排比对视口**：左侧展示 Godot 原作 2D 预渲染序列帧（带实时法线着色），右侧展示 Three.js 原生 3D 手捏模型；
- **FPS 动态调速**：控制 6 帧动画播放速率（0~24 FPS）；
- **法线凹凸滑块**：实时调节 Normal Map 凹凸强度（`0.0 ~ 3.0x`），观察动态阳光在 2D 贴图表面的光影凸起；
- **单帧审查**：点击 `F0` ~ `F5` 按钮单帧冻结审查。

### 2.3 模块三：3D 战场模拟器 (Battle Arena)
- 13×13 经典战场网格与可破坏红砖/钢块；
- 部署北侧东西双联防御炮台阵地；
- 智能敌军战车与工程抢修车电焊救援 AI；
- 真实多层黏土大爆炸与镜头震颤。
