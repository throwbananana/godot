# Sokpop 3D 黏土建模与 PBR 渲染管线设计规范 (Sokpop Clay 3D Pipeline Specification)

> **适用项目**：Tank Battle (Godot 4.5+ / Blender 5.2 LTS / Three.js WebGL 3D Studio)  
> **核心风格**：Sokpop 手捏陶土玩具美学 (Hand-Crafted Plasticine / Claymation Aesthetic)

---

## 1. 核心视觉哲学与三维设计原则

Sokpop 风格的本质是 **"鲜活的手作实体感 (Tactile Hand-Crafted Toy Physicality)"**。杜绝现代 3D 引擎常见的机械冷硬、工业平整与注塑塑料质感，所有资产均遵循以下 4 大三维造型准则：

### 1.1 手捏有机倒角与微形变 (Organic Bevel & Vertex Wobble)
- **拒绝死角**：任何几何形体均带有大半径平滑倒角（Bevel Radius: `0.04 ~ 0.18`），边缘圆润钝化。
- **微不对称手捏感**：所有几何体（箱体、圆柱、圆球）应用低频不规则顶点抖动（Perlin Noise Displacement），呈现手工揉捏时的轻微按压不对称。
- **倒角底板防黑缝标准**：瓦片底板尺寸采用 `TILE_PLATE_BLEED = 3.64`（略大于画幅半宽 + 倒角宽度），彻底消除网格拼接处的暗部镶边。

### 1.2 次表面透光与材质物理标定 (Subsurface Scattering & Sheen)
- **次表面散射 (SSS Weight: `0.25 ~ 0.45`)**：模拟黏土、软陶在强光透射下的半透光温润感，尤其是炮口、边缘薄壁与外挂零件。
- **陶土粗糙度 (Roughness: `0.65 ~ 0.85`)**：保持哑光质感，高光呈柔和漫反射斑块，避免镜面尖锐高光。
- **表面微凹凸 (Bump Scale: `0.35 ~ 0.55`)**：引入程序化高频微小指纹压痕（Fingerprints）与陶土颗粒杂质，近距离观察充满手作触感。
- **陶土微绒粉末感 (Sheen & Fuzz: `0.40 ~ 0.60`)**：边缘在掠射角下呈现浅色微粉反光。

### 1.3 色彩空间与明暗对比 (Color Space & Light Calibration)
- **色彩空间严防错配**：所有色值必须在 Linear-sRGB 下正确标定，杜绝蓝通道提亮发灰和去饱和。
- **视图变换**：采用 `Standard` 视图变换配合精调灯光，保留黏土的高纯度鲜明色调。
- **三点打光层级**：
  - **主定向阳光 (Sun Light)**：45° 俯角斜射（强度 `2.2 ~ 2.6`），产生清晰的玩具投射软阴影；
  - **天顶半球环境光 (Hemisphere Ambient)**：暖黄天空光（`0xfff0dd`）与泥土反射底光（`0x3d332a`），确保暗部饱满不死黑；
  - **冷色辅助补光 (Key Fill Light)**：淡青蓝色侧补光（`0x74b9ff`），勾勒轮廓并分离前景与背景。

## 2. 模型类别建模与装配参数规范

### 2.1 玩家战车族系 (Player Tanks Tier 0 ~ 3)
| 阶次 | 车体底盘 | 炮塔与武器装配 | 履带与配件 |
| :--- | :--- | :--- | :--- |
| **Tier 0** | 紧凑型双履带轻装甲手捏车身 | 单管短圆筒手捏主炮、球形炮塔 | 6 轮独立滚珠、车顶柔性通信天线 |
| **Tier 1** | 前突楔形倾斜装甲、防弹首上板 | 前突加长速射炮管、加厚前装甲防盾 | 8 轮重载履带、侧向工具箱 |
| **Tier 2** | 加宽重装底盘、排气散热格栅 | 阶梯错层双联重型火炮、后置供弹箱 | 重型防崩挡泥板、车尾双挂备用燃油桶 |
| **Tier 3** | 八边形磁浮科技底盘、反应堆散热孔 | 高能等离子终极主炮、聚能三棱透镜 | 悬浮推进器环、车身发光能量回路 |

### 2.2 敌军特化战车族系 (14 种敌机)
- **工程抢修车 (Engineer)**：3 节液压铰接旋转机械大臂、高亮青蓝焊枪电弧、双联氧气/乙炔气瓶、前置排障推土铲。
- **四足步行机甲 (Spider)**：分级父子骨骼铰接腿结构（基节 ➔ 股节 ➔ 膝关节 ➔ 胫节 ➔ 爪垫），顶部发光动力反应堆。
- **钻地沙虫 (Sandworm)**：5 节重叠硬壳环形体节，支持正弦波立体波浪蠕动与突刺撕咬。
- **分裂母机 (Splitter)**：反重力母船核心 + 4 架在空间中三维公转的伴随微型无人机。
- **车载火箭车 (Missile)**：八联装箱式液压升降导弹架，支持 45° 仰角抬升与曲射。
- **高能激光车 (Laser)**：旋转聚焦三棱透镜与保护外框，发射穿透激光柱。
- **超距狙击车 (Sniper)**：加长电磁轨道炮管、4 组聚能磁环与展开锁定入地双脚架。

### 2.3 史诗 Boss 族系 (Epic Bosses)
- **剧毒巨蝎 (Scorpion Boss)**：多段甲壳主躯干、双侧带锯齿开合主螯钳、六足步足骨骼、高耸蝎尾与发光毒刺总成。
- **太阳泰坦 (Titan Boss)**：四履带独立转向模块、双联巨炮、副炮塔矩阵与太阳金黄核心。
- **猛犸战舰 (Mammoth Carrier)**：重装复合外挂防盾、前突象牙冲角与多联导弹井。

## 3. 双端渲染同步与资产调用管线

1. **Godot 2D 离线预渲染流程**：
   - Blender 5.2 LTS 运行 `tools/build_all_sokpop_assets_unified.py` 或 `tools/rerender_tanks.py`；
   - 自动输出 `assets/sprites/` 下的 6 帧动画（`_f0.png` ~ `_f5.png`）与法线贴图（`*_n.png`）；
   - Godot 引擎通过 `AnimatedSprite2D` + `CanvasTexture` 加载并享受 2D 动态法线光照。

2. **WebGL 原生 3D 实时精修工坊 (Three.js Studio)**：
   - 本地服务通过软链接 `godot_assets` 直读 Godot 资产目录；
   - 支持在浏览器中实时 360° 检视、爆炸图部件拆解、2D 预渲染图与 3D 模型的并排对齐分析。
